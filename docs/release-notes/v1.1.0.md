# v1.1.0

## New

- **Spaces** (#46). Browse your desk’s spaces and tabs from the phone.
  Sideways swipes stay in the current tab, and Changes is now under More
  options.

## Fixed

- **Moving between agent screens** (#92). Moving between the terminal, chat,
  Changes and the tab overview now animates. Swipes, keyboard focus and
  TalkBack stay with the screen you’re on.
- **Reconnecting when you come back.** Switching back to Kudde now retries a
  machine that dropped right away, instead of waiting out the retry timer, and
  retries while you watch are never more than 10 s apart.
