# v1.2.0

## New

- **A guided first setup** (#93). The first time you open Kudde, a welcome
  explains four steps, and setup stays in front until a machine is really
  connected: find the machine, add this phone's key, connected, and alerts
  (optional). A bar at the top shows where you are. Adding another machine, or
  repairing one that stopped working, uses the same steps.
- **Let Kudde add the key for you.** Step 2 offers "kudde adds it for you":
  sign in once with the account's password and Kudde adds the phone's key and
  signs out. The password is used for that one run and never stored. You
  compare the machine's host key first, because a wrong key there would get
  the password; "Add it yourself" is still there and needs no password.
- **Setup says what it is doing and what went wrong.** A checklist shows
  signing in, adding the key and signing out, and a failure lands on the step
  that failed. When a machine can't be reached, the message says why.
- **A hint on your first terminal.** The first time a terminal or chat opens,
  a short note under the title bar explains how to move around from it. Tap
  it once and it doesn't come back.
- **Answer an agent's question from the chat** (#51). When Claude Code asks
  a multiple-choice question, the chat shows it as a card: pick an option,
  tick several where the question allows it, type your own answer, open an
  option's preview, or skip. With several questions you move between them
  freely, check your answers on a last step, and send them all at once. If
  the question was already answered at the desk, the card says so and sends
  nothing. Codex questions are still answered in the terminal. The card
  needs a small hook in Claude Code on your desk (see
  `docs/claude-code-question-hook.md`); without it, the card says how to
  add it.

## Changed

- Setup now asks for a screen lock before the first step, because the SSH key
  is kept in the phone's secure hardware.
